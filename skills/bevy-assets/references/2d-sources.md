# 2D 素材来源（免费）

## 首选

- **Kenney.nl**：CC0 全集（角色、UI、音效、tileset），风格统一、面向游戏；Bevy 官方示例同款素材来源。
- **Generic RPG Pack**（Bakudas / Gabe Fern）：CC0 通用 RPG 包，Bevy 官方文档引用。

## 社区与平台

- **OpenGameArt.org**：量大，但逐项看许可（CC0 / CC-BY / GPL 混存）。
- **Itch.io → Game Assets**：筛选 Free 或 Pay What You Want，看作者授权条款。

## 角色生成器

- **Universal LPC Spritesheet Generator**：选发型 / 服装 / 装备在线生成角色精灵表（含行走、攻击动画）；注意其开源许可的署名条款。
- **AIPixelKit**：AI 像素素材平台，可导出通用 LPC 精灵图；免费层需确认商用条款。

## 选择建议

- 原型期：Kenney 全套即可，风格统一，省去混搭调色。
- 需要独特角色动画：LPC 生成器。
- 下载后立即把来源与许可写入 `assets/LICENSES.md`。
