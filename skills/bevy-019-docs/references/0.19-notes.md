# Bevy 0.19 关键差异速查

> 只列易错点与迁移项；完整用法以 docs.rs 与官方示例为准。

## 通信：Message 与 Event 分家

- **Message**：`#[derive(Message)]` + `app.add_message::<T>()`；`MessageWriter<T>` 写入、`MessageReader<T>` 读取；双缓冲存活 2 帧，未消费自动清理。适合系统间批量、解耦、有序的广播。
- **Event（全局 `GlobalTrigger`）/ EntityEvent（实体 `EntityTrigger`）**：配合 `Observer`（系统函数首参为 `On<T, B>`），用 `commands.trigger` / `trigger_targets` 即时触发。适合定向实体、需要立即生效的响应。
- `EventReader` / `EventWriter` 已移除；`Message` 不会触发 `Observer`，两者不可混用。

## 场景与资产

- glTF：`asset_server.load("models/x.glb#Scene0")`；生成实体用 `WorldAssetRoot(handle)`（替代旧 `SceneBundle`）。
- 批量：`asset_server.load_folder("dir/")`。
- 热重载：开发时启用 `file_watcher` feature（dev 特性集合已包含）。
- 像素风：`DefaultPlugins.set(ImagePlugin::default_nearest())`。
- 图集：`TextureAtlasLayout::from_grid(UVec2, cols, rows)`；动画参考官方 `examples/2d/sprite_sheet.rs`。

## 组件、查询与场景标记

- `#[require(...)]` 声明并自动补齐必需组件。
- 组件钩子：`#[component(on_add = ...)]`（另有 on_insert / on_remove / on_replace）。
- 查询：`Single<T>` / `Populated<T>`。
- `Relationship` 实体关系；BSN 用 `bsn!` 宏写代码内场景模板。

## 输入、UI 与计时

- `ButtonInput` 轮询 + `MessageWriter` 广播；物理键 `KeyCode` 优先。
- 复杂映射可用 `bevy_enhanced_input`（面向 Observer；选用时核对 Bevy 0.19 兼容版本表）。
- UI 由 `Node` 布局驱动，不依赖 `Transform`；默认字体无 CJK。
- `Timer` 自 0 向上 tick：全局计时放 `Resource`，技能 CD 放 `Component`，单系统用 `Local<Timer>`。

## 测试

- 逻辑测试：`App::new()` + `MinimalPlugins` + 业务 `AppPlugin`，不启动渲染。

## 禁用清单（旧 → 新）

| 旧写法 | 0.19 写法 |
| :--- | :--- |
| `EventReader<T>` / `EventWriter<T>` | `MessageReader<T>` / `MessageWriter<T>`，或 Event + Observer |
| `SceneBundle` | `WorldAssetRoot` |
| `Camera2dBundle` / `Camera3dBundle` | `Camera2d` / `Camera3d` 组件 |
| `app.add_state::<S>()` | `app.init_state::<S>()` |
