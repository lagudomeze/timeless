# 实机核查清单（每改 UI / 交互后跑一遍）

> 来源：`docs/backlog/docs.md` 的 #63。定这份清单的理由很直接——
> 有 5 条界面 bug（面板说反话、时间轴说谎、日志句式拼错……）**单测全绿却实机可见**，
> 所以"跑一遍验收命令"不够，还要有人真的用一遍。
>
> 用 BRP 做：`brp_extras_send_keys` / `move_mouse` / `click_mouse` / `screenshot`，
> 状态用 `world.get_resources` / `world.query` 读。**恢复干净的起点用 `F5`。**

## 0. 启动

```bash
cargo run          # ⚠️ 不要与 cargo test 并行：两者抢 target 锁
```

- [ ] 无 panic；控制台没有资产加载错误（`已从 config/actions.ron 装载动作数值` /
      `已注册 6 种方块材质` / `BRP extras enabled`）
- [ ] 存档行为符合预期（`💾 没有存档：从新世界开始` 或读到上次的改动）

## 1. 键盘

- [ ] 方向键：走**一格**，停在格中心
- [ ] `X` + 方向键：**跨两格**（与方向键对照，一步之差要看得出来）
- [ ] `1`~`5`：直接放对应技能；`Tab` / `Shift+Tab` 在**付得起**的技能间循环
- [ ] `Q` / `W` / `E` / `R`：火球 / 横扫 / 翻滚 / 招架
- [ ] `G`：放当前选中的技能 · `C`：跳跃（不可打断）
- [ ] `Space`：等待（占住决策槽、世界继续跑）· `P`：暂停 / 恢复
- [ ] `B` / `V`：在**悬停格**放 / 挖方块（堆高之后能站上去、也能被挡住）
- [ ] `T`：穿脱装备（面板的 `arm` 读数要跟着变）
- [ ] `F5`：重置 · `F1`：打开 / 关闭帮助

⚠️ **用 MCP 注入按键时每个键只按一次**（见下节"已知坑"）：同一个键连按两次，
第二次往往不会触发 `just_pressed`。

## 2. 鼠标

- [ ] 左键**空地**：走到那一格（多格时逐格检查可行走性）
- [ ] 左键**单位**：用当前选中的技能打它
- [ ] 右键：撤销**还没到点**的那一手；威胁窗口里 = 放弃反制
- [ ] 中键拖拽：平移镜头（松开后镜头把上一段移动追完）
- [ ] 滚轮：缩放（夹在最近 / 最远之间）

## 3. UI 穿透（#46 的守门）

- [ ] 在每个面板上点一下，**世界不动**：玩家面板 / 敌人面板 / 技能栏 / 战斗日志
      （含标题与正文）/ 提示条 / 时间轴 / 帮助面板
- [ ] 光标压在面板上时：`HoveredCell` 变 `None`、战场高亮与 AOE 预演**消失**、
      提示条收起、`PointerOverUi` 为 `true`
- [ ] `F1` 收起帮助面板后，世界立刻能再点（不能永久点不动）

## 4. 冻结（三种原因都要能显示出来）

- [ ] `awaiting`：玩家空闲 → 顶栏 `TIMELINE · FROZEN · awaiting`
- [ ] `threat`：敌人前摇 / 投射物在飞 → `FROZEN · threat`，战场上有威胁格
- [ ] `manual`：忙碌时按 `P` → 状态行**必须**变 `FROZEN`（#50 就是这里说反话）
- [ ] 三种叠加时按字母序拼出来（`awaiting + manual`）

## 5. HUD 读数

- [ ] 面板：`HP` / `EN` / `ammo` / `arm` / **`FOCUS n / 3` + 三点** /
      `act: <技能> (windup …)`；**`ready` / `busy` 的语义要和决策槽一致**
      （玩家空闲 = `ready`，敌人前摇中 = `busy`）
- [ ] 敌人面板：每行一名敌人、按"离玩家最近"排序、行数超限时有溢出计数
- [ ] 时间轴：每单位一条车道、色块从 `now` 起算、块内刻线 = 落地时刻、
      右侧候场区列出"已就绪还没声明"的人
- [ ] 技能栏：选中 / 悬停 / 买不起（灰）/ **能当反制（高亮）** 四种状态可区分
- [ ] 日志：中文正文、`[1.2s]` 时刻前缀、能折叠、句子读得通（**不能出现
      「敌人玩家 …」这种两个标签贴在一起**）
- [ ] 提示条：被拒的输入优先于预演读数；威胁窗口开着时**持续显示**（不淡出）

## 已知坑（别重复踩）

1. **MCP 注入输入的"松手"依赖时钟**：`bevy_brp_extras` 的按键松手按时钟计，
   而这个世界大部分时间是冻结的 → 松手定时器不到点 → 那个键**一直是按下状态**，
   **同一个键按第二次不会触发 `just_pressed`**。
   看到"某个键没生效"时，先确认它不是"还按着"：按一下空格让世界跑一秒，再试。
2. **BRP 的合成光标驱动不了 `Interaction`**（Bevy 每帧重算它）：所以"鼠标真的悬停在
   UI 上"这一步实机验不了，只能靠测试守；实机能验的是 `PointerOverUi` / `HoveredCell`
   这类**我们自己的资源**。
3. **查不到 ≠ 不存在**：没派生 `Reflect` 的组件在 BRP 里等于不存在，`world.query`
   会**静默返回空**。排查"东西没生成"之前先确认它进了反射表
   （有测试 `the_diagnostic_anchors_are_reflected` 守着）。
