# 游戏设计总纲

## 定位与灵感

以 ToME4 式回合制战棋为基底，融合《黑神话》的「资源置换 / 见招拆招」、《戴森球计划》的供应链、《Elin》的生态因果与 Noita/ToME4 的「知识型成长」。核心乐趣是**预读博弈**，不依赖手速。

## 核心循环：We-Go 同步时间线

- 所有单位**同时规划、同时执行**：决策阶段时间冻结，玩家与 AI 各自锁定行动；执行阶段按逻辑刻度统一推进。
- **帧不是 Bevy 真实时间**，而是逻辑刻度——结算器里的指针/索引，由 `Resolving` 队列驱动。
- 决策阶段，帧表现为静态窗口坐标；执行阶段，帧只作为排序权重（谁先命中）。

## 三层裁决

命中判定按顺序比较：**攻击帧 → 距离 → 破势**。先到帧者先命中；帧相同比距离；再相同则比较破势（消耗对方架势槽）。

## 时间线特权（玩家独有）

1. 决策阶段可**无限撤销**（AI 决策锁定后不可撤销，但可设防/闪避/格挡——这是独立决策，不是取消）。
2. 攻击**前摇窗口**内检测到威胁时，可消耗精力执行**翻滚取消（Roll Cancel）**，中断攻击并闪避。
3. 特权编码在系统层（如 `CancelPrivilege` 组件守卫），不靠数据约定；怪物动作的 `cancelable_by` 恒为空。

## 外置资源

- **弹药 / 精力分线**：基础平 A 免费；重击、射击、翻滚分别消耗弹药与精力。
- 取消是惩罚性的：消耗的弹药不退还；翻滚与翻滚取消共用 3s 冷却。
- 资源置换 = 高风险高回报，构成「黑神话式」的取舍快感。

## 信息即力量

- 升级 = 获得**洞察力 / 信息权限**：查看怪物数据、帧窗口细节、战斗日志、死亡复盘。
- **死亡即学习**：失败成本低、信息回报高，成长曲线以知识而非数值为主。

## 规则引擎

- **标签 + 元素反应**：状态与效果基于可配置规则（如 元素/标签 → 反应产物）。
- **刚性核心 + 柔性 Mod**：克制系数、冷却、成本等均配置化（serde + ron / Asset），数值层可热调。

## 随机与手工的平衡

- 约 80% 固定公式（合成、掉落表），20% 随机点缀；随机提供重复可玩性，手工提供史诗感。
