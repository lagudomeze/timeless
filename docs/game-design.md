## 定位与灵感

以 ToME4 式回合制战棋为基底，融合《黑神话》的「资源置换 / 见招拆招」、
《戴森球计划》的供应链、《Elin》的生态因果与 Noita / ToME4 的「知识型成长」。
核心乐趣是**预读博弈**，不依赖手速。

## 核心乐趣：预读，而不是手速

战斗是**无回合**的：谁能决策由各自的决策槽（`DecisionSlot`）决定，每个动作自带
前摇 + 后摇，只在玩家等待输入（或**威胁逼近**）时冻结世界。玩家做的事是：

1. 读敌人的**意图**（HUD 提前显示）与前摇窗口；
2. 决定自己这一手是打、是走、是防；威胁压过来时还有一个反应窗口：
   撤销、换手，或者花 1 点 **Focus** 把前摇买掉抢先出手；
3. 承担选择的后果——声明即生效，反悔要付代价（打断 / 撤销）。

「我打两下、敌人打一下」这类节奏来自动作表（前摇 / 后摇），不来自回合数。

## 打断：打的是「还没发生的事」

谁能先出手由各自的 `execute_at` 决定，不再需要"同刻相撞"的裁决。
**打断**改成对**还没到点的那一手**做掷骰对抗（力度 vs 打断抗性）：
赢了就把对方的前摇抹掉，对方立刻拿回决策槽。纯逻辑见
`src/combat/formula/domain.rs`，语义见 [timeline.md](timeline.md) 第五 / 第四节。

## 资源置换

- **精力（`Stamina`）**：翻滚 / 招架 / 火球的货币，每次重新可决策回 1 点。
  「一直滚」会把自己滚空——这是当前唯一的资源线。
- **Focus（反应资源）**：上限 3，每 10 虚拟秒回 1 点。花 1 点可以把**这一手的前摇
  归零**——威胁窗口里唯一能"抢在对方出手前动起来"的手段，因此它买的是反应速度。
- **取消代价**：撤销不是免费的。退款规则挂在**花钱的那个领域**（火球撤销退 2 收 2、
  近战撤销收 1），行动自己只带 `Uncancellable` 这一条"能不能撤"；
  「赶路调整方向」免费，「大招打断」要付钱。
- **目标形态**（**未落地**）：资源分线——弹药（重击 / 射击）、架势槽（格挡 / 硬直）。
  平 A 免费，让玩家始终有牌可打。

## 信息即力量

- 升级 = 获得**洞察力 / 信息权限**：查看怪物数据（帧 / 射程 / 打断抗性 / 血量）、
  帧窗口细节、战斗日志、死亡复盘。
- **死亡即学习**：失败成本低、信息回报高，成长曲线以知识而非数值为主。
- 当前的落地形态：HUD 时间轴（谁在什么时候动手 + 世界为什么冻结）、敌人意图、
  预演读数（这一手会变成什么 / 多远 / 多少伤害）、中文战斗日志。

## 规则引擎（目标形态）

- **标签 + 元素反应**：状态与效果基于可配置规则（如 元素 / 标签 → 反应产物）。
- **刚性核心 + 柔性 Mod**：克制系数、冷却、成本等配置化（serde + ron / Asset），
  数值层可热调。当前数值仍硬编码在 `timeline/timing.rs` 与 `SKILLS` 里。

## 随机与手工的平衡

约 80% 固定公式（合成、掉落表），20% 随机点缀；随机提供重复可玩性，
手工提供史诗感。
