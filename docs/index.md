# Project Timeless — 文档入口

> 本文件是项目文档的**唯一入口**。改动文档后同步本页的表格。

## 项目定位

**无回合**战斗时间线 + 戴森球式供应链 + 「信息即力量」的 roguelike 策略游戏，
基于 **Bevy 0.19.1**。

节奏来自三件事：每个单位自己的决策槽（谁能决策）、每个动作自带的前摇 + 后摇、
以及**暂停原因集合**（等玩家决策 / 手动暂停 / 威胁逼近）。
结算用**真实距离**，决策与同格判定按**格子**。

## 维护规则（防漂移）

1. **进度只写 `TODO.md`**：其他文档只写「设计与约定」，不写「做到哪了」。
2. **勾选要有验收证据**：命令输出、测试名或控制台片段；没有证据就保持 `[ ]`。
3. **不引用不存在的标识符**：文档里出现的类型名必须能在 `src/` 里 grep 到；
   目标设计里还没落地的部分**必须标 🚧 或在文首声明**。
4. **改动代码后同步受影响的篇**（地基三篇 + 对应专题篇）。
5. **一篇只回答一个问题**；一篇超过 300 行就该拆。
6. **不用 `#[ignore]` 隐藏失败**：要么修好，要么在 `TODO.md` 写明根因与下一步。
